01 / THE MECHANISMHOW IT WORKS

A crowd is made of individuals.

Instead of programming what a crowd will do, we give every student a few simple rules. The patterns are allowed to emerge on their own.

01

Unaware

Has not adopted the rumour. Does not spread it.

STARTING STATE
02

Believer

ACTIVE SPREADER
03

Verified

Has fact-checked and will no longer spread it.

NON-SPREADER
✳

The model does not determine if a rumour is true. “Verified” means an agent has stopped spreading after the fact-checking step.

04 / THE METHOD

Four rules.
One unpredictable outcome.

01 / INITIALIZE

Start with a few believers.

Place the agents at random locations, assign their states, and set the clock to zero.

02 / MOVE

Let students wander.

Every tick, students turn by small random angles and move forward by 0.5 world units.

•→•↗•
03 / TRANSMIT

Make contact, not broadcasts.

Believers attempt to pass the rumour to unaware agents within 1.5 units, with a set probability.

•⤳•⤳•
04 / FACT-CHECK

Some stop passing it on.

Each believer independently gets another chance to fact-check during each tick. Then the chart updates.

•→✓non-spreader
MODEL INVARIANTUnaware + Believers + Verified = Population
